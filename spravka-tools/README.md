# Справочник САФУ — как собирается

Страница https://arktika-app.ru/spravka/ отвечает на вопросы студентов **только дословными цитатами** из документов САФУ.
ИИ здесь нет: поиск по словам работает прямо в браузере (`engine.js`), а ответ — это текст пунктов как есть.

## Из чего состоит

| Файл | Что это |
|---|---|
| `../site/spravka/data/spravka.json` | документы, пункты (дословно) и частые вопросы — всё, что грузит страница |
| `cards.py` | частые вопросы → какие пункты показать и какие фразы подсветить (подбирается вручную) |
| `engine.js` | поиск: нормализация, основы слов, разговорные синонимы («общага», «хвосты», «академ»), BM25 |
| `ui.js`, `page_head.html` | интерфейс чата; `assemble.sh` собирает из них `../site/spravka/index.html` |
| `parse_docs.py`, `parse_pages.py`, `build_corpus.py`, `export.py` | PDF и страницы narfu.ru → `spravka.json` |
| `validate.py` | все пункты из `cards.py` существуют, все фразы есть в тексте дословно |
| `verify_verbatim.py` | каждый пункт совпадает с исходным документом (без учёта переносов строк) |

## Источники (снимок 27.10.2026)

PDF с https://narfu.ru/sveden/document/:
- Положение о текущем контроле успеваемости и промежуточной аттестации (приказ № 48-П от 23.07.2026);
- Положение о порядке отчисления, восстановления и перевода (приказ № 1010 от 28.11.2022, изменения № 53-П касаются только п. 1.2);
- Правила внутреннего распорядка обучающихся (№ 553 от 01.07.2019);
- Положение о режиме занятий (№ 764 от 30.09.2019);
- Порядок оформления отношений (№ 652 от 02.09.2019).

Страницы narfu.ru: «Стипендия» (академическая, социальная, повышенная, материальная поддержка, размеры, именные), «Поддержка студенческих семей», «Общежития», «Предоставление места в общежитии», «Оплата проживания».

Порядок распределения стипендиального фонда (П742) с 13 приказами об изменениях пока не разобран: по стипендиям справочник отвечает по страницам сайта.

## Обновить

1. Скачать PDF в `docs/txt/` (через `pdftotext -layout`), страницы — в `docs/pages/` (`narfu.ru_<путь с _ вместо />`). Эти файлы в репозиторий не кладём.
2. `python3 parse_docs.py && python3 parse_pages.py && python3 build_corpus.py && python3 export.py`
3. `python3 validate.py && python3 verify_verbatim.py && sh assemble.sh`
