# САФУ — приложение для студентов САФУ

Неофициальное приложение для iPhone и Android для студентов и преподавателей Северного (Арктического) федерального университета: расписание, пары на экране блокировки, файлы по предметам, почта и учебные сайты в одном месте.

Приложение сделал студент группы 151621 (ВШИТАС). Код открыт: исходники лежат в `SAFU.zip`, а готовые сборки — в разделе [Releases](../../releases).

## Возможности

**Расписание**
- Расписание группы из [РУЗ САФУ](https://ruz.narfu.ru) подтягивается автоматически после регистрации: школа → группа → готово
- Уведомления о заменах и отменах пар, даже когда приложение закрыто
- Звонки, недели, архив прошлых недель, отправка расписания дня в чат группы
- Свободные аудитории и где сейчас идёт пара

**Экран блокировки и главный экран**
- Live Activity: текущая пара с таймером на экране блокировки и в Dynamic Island
- Виджет с текущей и следующей парой, несколько стилей, «прозрачный» вариант с фоном из обоев

**Учёба**
- Файлы по предметам, сканер документов, фото доски по парам и PDF со всеми фото пары
- Заметки, задачи, режим сессии с билетами, баллы БРС и прогноз оценки
- Титульные листы для отчётов, запись и конспекты лекций
- Посещаемость и рассылка группе для старост

**Сайты университета внутри приложения**
- Sakai, почта Samoware, Р7-Офис, личный кабинет, РУЗ
- Уведомления о новых письмах в почте САФУ и число непрочитанных на иконке
- Сохранение входа и кнопка «Вставить пароль»; пароли хранятся в связке ключей iPhone и защищены Face ID

**Для преподавателей (бета)**
- При регистрации можно выбрать «Я преподаватель»: приложение собирает ваши пары из расписаний всех групп САФУ
- Полное расписание любого преподавателя, посещаемость, рассылка, сайты для сотрудников (Антиплагиат.ВУЗ, МООК и др.)

**Оформление**
- Темы, фоны, стили карточек, шрифты, размер текста, настройка главного экрана перетаскиванием
- Вход по Face ID, скрытие экрана в переключателе приложений

## Конфиденциальность

- Все данные — расписание, файлы, фото, пароли — хранятся **только на телефоне**. У приложения нет своего сервера.
- Пароли — в связке ключей iPhone, без синхронизации и без резервных копий.
- Приложение обращается только к открытым сайтам университета (РУЗ и сайты, которые вы открываете сами) и к сервису погоды Open-Meteo.
- Уведомления о письмах (если включить) — приложение само заходит в ваш ящик по IMAP напрямую на сервер почты САФУ и смотрит только отправителя и тему новых писем. Письма не скачиваются и не помечаются прочитанными.
- Резервную копию можно сделать вручную: Профиль → Резервная копия.

## Установка

Приложения нет в App Store. Готовый файл `.ipa` лежит в [Releases](../../releases). Его устанавливают через AltStore, SideStore, Sideloadly или похожие программы.

Требования: iPhone с iOS 17 или новее.

### Android

Готовый `SAFU.apk` лежит в [Releases](../../releases) (релизы «САФУ для Android»). Скачайте его на телефон, откройте и разрешите установку из этого источника. Обновления ставятся поверх, данные сохраняются.

- `SAFU.apk` (он же `…-arm64.apk`) — для всех телефонов последних лет, `…-armv7.apk` — для старых 32-битных.
- Требования: Android 8.0 или новее.
- Всё то же, что на iPhone. Отличия от iOS: вместо Live Activity — закреплённое уведомление с отсчётом до конца пары и до автобуса; вход по отпечатку или разблокировке телефона вместо Face ID; речь лекций распознаёт Vosk на телефоне; конспекты пишет GigaChat, Claude или простой конспект без ИИ (ИИ Apple на Android нет).
- Резервная копия `.safubackup` общая: её можно перенести с iPhone на Android и обратно.

## Сборка из исходников

Проект описан в `project.yml` для [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
unzip SAFU.zip && cd SAFU
brew install xcodegen
xcodegen generate
open SAFU.xcodeproj
```

Каждая загрузка в репозиторий автоматически собирается через GitHub Actions (`.github/workflows/build.yml`), и готовый `.ipa` появляется в Releases.

**Структура:**
- `Sources/` — приложение (SwiftUI)
- `Shared/` — общий код приложения и виджета: РУЗ, расписание, Live Activity
- `Widget/` — виджеты и Live Activity

### Android

Исходники — в папке `android/` (Kotlin, Jetpack Compose). Нужны JDK 17+ и Android SDK 36.

```bash
cd android
./gradlew :app:assembleRelease      # APK: app/build/outputs/apk/release/
./gradlew :app:testDebugUnitTest    # проверки и снимки экранов: app/build/shots/
```

Каждая загрузка в `android/` собирается через GitHub Actions (`.github/workflows/android.yml`), и готовые APK появляются в Releases.

Секреты репозитория (все необязательные):
- `YANDEX_MAPKIT_KEY` — ключ Яндекс MapKit для карты транспорта (без него — карта OpenStreetMap);
- `SAFU_KEYSTORE_BASE64`, `SAFU_KEYSTORE_PASSWORD`, `SAFU_KEY_ALIAS`, `SAFU_KEY_PASSWORD` — свой ключ подписи. Без них APK подписывается открытым ключом из `android/app/safu-ci.jks`: обновления ставятся поверх, но таким ключом может подписать любой. После перехода на свой ключ приложение нужно один раз переустановить.
