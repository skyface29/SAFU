# Арктика — пары и учёба

**Арктика** — неофициальное приложение для студентов и преподавателей Северного (Арктического) федерального университета: расписание, домашка, пары на экране блокировки, файлы и фото доски по предметам, почта и учебные сайты в одном месте. Есть для iPhone и для Windows.

Приложение сделал студент группы 151621 (ВШИТАС). Код открыт для чтения: исходники лежат в `SAFU.zip`, а готовые сборки — в разделе [Releases](../../releases). Это не свободная лицензия — изменять, копировать и распространять приложение без разрешения автора нельзя (см. [Лицензия](#лицензия)).

## Возможности

**Расписание**
- Расписание группы из [РУЗ САФУ](https://ruz.narfu.ru) подтягивается автоматически после регистрации: школа → группа → готово
- Уведомления о заменах и отменах пар, даже когда приложение закрыто
- Звонки, недели, архив прошлых недель, отправка расписания дня в чат группы
- Свободные аудитории и где сейчас идёт пара

**Экран блокировки и главный экран**
- Live Activity: текущая пара с таймером на экране блокировки и в Dynamic Island
- Виджет с текущей и следующей парой, несколько стилей, «прозрачный» вариант с фоном из обоев

**Домашка**
- Срок сам встаёт к следующей очной практике предмета и переезжает, если пару перенесут
- Нажал на задание — красивая карточка: записанное как попало оформляется само («стр. 45», «№ 5, 6», списки по пунктам)
- «Отправить ребятам»: задание картинкой или текстом, срок и фото — в чат группы одной кнопкой; подборка ДЗ на завтра или неделю

**Учёба**
- Учебники в PDF открываются там, где остановился
- «Библиотеки» одной кнопкой: Знаниум, Лань, Юрайт, IPR SMART, Консультант студента, eLibrary, КиберЛенинка, НЭБ и библиотека САФУ
- Файлы по предметам, сканер документов, фото доски по предметам и датам, PDF со всеми фото пары
- Матрицы по фото: определитель, обратная, ранг, системы уравнений и решение по шагам
- Заметки, задачи, режим сессии с билетами, баллы БРС и прогноз оценки
- Титульные листы для отчётов, запись и конспекты лекций
- Посещаемость и рассылка группе для старост

**Сайты университета внутри приложения**
- Sakai, почта Samoware, Р7-Офис, личный кабинет, РУЗ
- Уведомления о новых письмах в почте САФУ и число непрочитанных на иконке
- Сохранение входа и кнопка «Вставить пароль»; пароли хранятся в связке ключей iPhone и защищены Face ID

**Для преподавателей (бета)**
- При регистрации можно выбрать «Я преподаватель»: приложение собирает ваши пары из расписаний всех групп САФУ
- Полное расписание любого преподавателя, посещаемость, рассылка, сайты для сотрудников (Антиплагиат.ВУЗ, МООК и др.)

**Синхронизация с компьютером**
- Один раз связываешь iPhone с Арктикой на Windows по QR-коду — и ДЗ, задачи и заметки общие: отметил ДЗ сделанным на компьютере — через пару секунд оно сделано на телефоне, и наоборот
- По домашнему Wi‑Fi, напрямую и с шифрованием AES‑256, без облаков; если поменял одно и то же в двух местах — побеждает поздняя правка, по каждому полю отдельно
- iPhone: Профиль → Синхронизация с компьютером; Windows: Профиль → Синхронизация с iPhone

**Перенос на компьютер по QR-коду**
- Открой Арктику на Windows → «Перенос с iPhone», наведи камеру iPhone на код — файлы предметов, фото доски, записи лекций, ДЗ, задачи, заметки, оценки и настройки перелетят по Wi‑Fi
- Напрямую, без интернета, облаков и кабеля; шифрование AES‑256 ключом из QR-кода, который меняется каждый раз
- Обрыв связи — продолжит с того же места; повторный перенос шлёт только новое; на компьютере ничего не перезаписывается
- На iPhone перенос открывается кнопкой с QR-кодом в правом верхнем углу главной

**Оформление**
- Темы, фоны, стили карточек, шрифты, размер текста
- Главный экран как рабочий стол iPhone: зажми значок или блок — всё покачивается, соседи расступаются, пока тащишь
- Вход по Face ID, скрытие экрана в переключателе приложений

## Конфиденциальность

Полная политика: [PRIVACY.md](PRIVACY.md). Подготовка к App Store: [APP_STORE.md](APP_STORE.md).

- Все данные — расписание, файлы, фото, пароли — хранятся **только на вашем устройстве** (iPhone или компьютере). У приложения нет своего сервера, разработчик ничего не получает.
- Пароли на iPhone — в связке ключей только этого устройства, на Windows — под шифрованием Windows (DPAPI). Открытым текстом они не хранятся нигде, а в резервную копию на Windows попадают только зашифрованными паролем копии.
- Приложение обращается к РУЗ, сайтам университета (сайты, которые вы открываете, и Sakai с личным кабинетом — за баллами БРС, если вы там уже вошли), погоде Open-Meteo, Яндекс Картам (карта транспорта) и один раз к Hugging Face — скачать модель распознавания речи. Полный список — в [PRIVACY.md](PRIVACY.md).
- ИИ-конспект лекций: текст расшифровки уходит в GigaChat или Claude, только если вы сами ввели свой ключ и разрешили отправку. Аудио не отправляется.
- Уведомления о письмах (если включить) — приложение само заходит в ваш ящик напрямую на сервер почты САФУ (тем же способом, что и сайт почты, запасной вариант — IMAP) и смотрит только отправителя и тему новых писем. Письма не скачиваются и не помечаются прочитанными.
- Резервную копию можно сделать вручную: Профиль → Резервная копия.
- Перенос и синхронизация с компьютером идут напрямую по домашней сети Wi‑Fi, зашифрованными. Синхронизация включается, только когда вы сами связали телефон с компьютером: выбрали компьютер на iPhone, сверили код на обоих экранах и нажали «Разрешить» на компьютере — или отсканировали QR-код с его экрана.

## Установка

Приложение готовится к выходу в App Store (см. [APP_STORE.md](APP_STORE.md)). Пока готовый файл `.ipa` лежит в [Releases](../../releases) — его устанавливают через AltStore, SideStore, Sideloadly или похожие программы.

Требования: iPhone с iOS 17 или новее.

## Сборка из исходников

Собирать можно только без изменений и только для себя — условия в [LICENSE](LICENSE).

Проект описан в `project.yml` для [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
unzip SAFU.zip && cd SAFU
brew install xcodegen
xcodegen generate
open SAFU.xcodeproj
```

Каждая загрузка в ветку `main` автоматически собирается через GitHub Actions (`.github/workflows/build.yml`), и готовый `.ipa` появляется в Releases. Ветка `dev` собирается для проверки — `.ipa` лежит в артефактах запуска, без релиза. Сборка для App Store и TestFlight — workflow `appstore.yml`, запускается вручную.

**Версия для Windows** лежит в папке [`windows/`](windows/README.md) (Electron): каждая загрузка в `main` собирает установщик `.exe` через `.github/workflows/windows.yml` — он появляется черновиком в Releases (сборки `win-…`).

**Структура:**
- `Sources/` — приложение (SwiftUI)
- `Shared/` — общий код приложения и виджета: РУЗ, расписание, Live Activity
- `Widget/` — виджеты и Live Activity
