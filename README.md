# Данные расписания РУЗ САФУ

Эту ветку пишет сборщик `ruz/collect.mjs` (задача «Расписание РУЗ» в Actions) — руками не трогать.

- `latest.json` — последнее известное расписание всех групп
- `status.json` — работает ли РУЗ и когда проверяли
- `changes.json` — правки за 60 дней
- `snapshots/` — все копии; `index.json` — их список
