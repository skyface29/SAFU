# Помощник антиплагиата (arktika-app.ru/antiplagiat/)

Проверка текста идёт прямо в браузере (`site/antiplagiat/engine.js`): текст никуда не отправляется. Википедия
отвечает браузеру напрямую, а чужие сайты, выдачу поисковиков и поиск КиберЛенинки браузер прочитать не может —
у них нет разрешения CORS. Их скачивает этот помощник: `GET ?url=<адрес>` → тело страницы как есть.

| Файл | Что делает |
|---|---|
| `yandex.js` | функция Yandex Cloud (основной вариант: из России открывается везде, сайты видят российский адрес) |
| `worker.js` | Cloudflare Worker (запасной вариант, тот же протокол) |

Протокол:

- `GET` без параметров → `{"ok":true}` — страница так проверяет, что помощник жив;
- `GET ?url=…` → тело страницы (до 2,5 МБ); код ответа сайта — в заголовке `X-Status`, итоговый адрес — в `X-Final-Url`;
- `POST ?url=https://cyberleninka.ru/api/search` → поиск КиберЛенинки (другие адреса для POST запрещены).

Помощник ничего не хранит. Скачивает только из открытого интернета: адреса внутренних сетей, IP-адреса вместо имён
и нестандартные порты запрещены (в `yandex.js` проверяется и то, куда ведёт имя, на каждой переадресации). Ответы
с разрешением CORS получают только `arktika-app.ru` и `localhost:8790`.

## Как работает сейчас

Функция Yandex Cloud `antiplagiat` (каталог `default`, рядом с `otmetki`): Node.js 22, `index.handler`, 128 МБ,
таймаут 15 с. Адрес `https://functions.yandexcloud.net/d4er34jsfe1f9gqu4vg8` вписан в `API_DEFAULT`
в `site/antiplagiat/index.html`. Функция должна быть **публичной** — иначе страница проверяет только по Википедии.

## Проверить у себя

```
python3 antiplagiat/site_dev.py
```
Открыть `http://localhost:8790/antiplagiat/` — на localhost страница сама использует встроенного помощника `/proxy`.

## Выложить (бесплатно, как функцию «Отметок»)

1. Yandex Cloud → Cloud Functions → «Создать функцию», имя `antiplagiat`.
2. Сделать функцию **публичной**.
3. Редактор: среда **Node.js 22**, точка входа `index.handler`, в файл `index.js` вставить содержимое `yandex.js`.
4. Параметры: память **128 МБ**, таймаут **15 секунд**. Создать версию.
5. Скопировать ссылку вида `https://functions.yandexcloud.net/…` и вписать её в `API_DEFAULT` в
   `site/antiplagiat/index.html`.

Бесплатно в месяц: 1 млн вызовов и 10 ГБ×ч. Одна проверка — около 60–200 вызовов по ~1 секунде на 128 МБ, то есть
бесплатного объёма хватает примерно на 5 тысяч проверок в месяц. Без привязанной карты при превышении функция
просто перестаёт отвечать до следующего месяца, а страница продолжает проверять по Википедии.

Cloudflare (запасной вариант): Workers → «Create» → вставить `worker.js` → Deploy; ссылку `…workers.dev` можно
вписать в `API_DEFAULT` вместо функции Yandex. Бесплатно 100 тысяч запросов в день.

**Учти:** помощник — открытый «скачиватель страниц». Браузеры с чужих сайтов им воспользоваться не смогут
(нет разрешения CORS), но программа, написанная специально, — сможет, в пределах бесплатных лимитов.

## Поиск Яндекса (платная полная проверка)

`yandex.js` умеет искать через Yandex Search API v2 в отложенном режиме (30,5 ₽ за 1000 запросов днём,
25,4 ₽ ночью). Выключено, пока не задано `YSEARCH=on`. Одна полная проверка — примерно 30–80 запросов, то есть 1–2,5 ₽.

1. Привязать карту в биллинге Yandex Cloud.
2. Создать сервисный аккаунт с ролью `search-api.webSearch.user` и выбрать его в настройках функции `antiplagiat`.
3. Переменные функции: `YSEARCH=on`, `FOLDER_ID=<каталог>`, `TICKET_SECRET=<длинная случайная строка>` (та же, что у
   `antiplagiat-pay`), при желании `YSEARCH_DAILY=5000` — потолок запросов в сутки на экземпляр.

С `TICKET_SECRET` поиск Яндекса работает только с билетом полной проверки (`GET ?ysearch=<фраза>&t=<билет>`, без билета —
402). Без `TICKET_SECRET` он открыт всем, поэтому включать `YSEARCH=on` только вместе с ним.

## Оплата (`pay.js`)

Оплата через Robokassa: у самозанятых чеки уходят в «Мой налог» сами («Робочеки СМЗ»). ЮKassa с 29.12.2025
сервисы для самозанятых не поддерживает. Тарифы — `PLANS` в начале `pay.js` (сейчас 49 ₽ / 149 ₽ / 299 ₽).

Как работает: страница просит `create` → получает ссылку на оплату → после оплаты Robokassa присылает уведомление на
ResultURL → функция сверяет подпись (Пароль №2) и сумму и выдаёт код `AIS-XXXX-XXXX` → перед каждой полной проверкой
страница обменивает код на билет (`ticket`, списывается одна проверка) → билет проверяет `yandex.js`.

Выложить: отдельная функция `antiplagiat-pay`, Node.js 22, точка входа `pay.handler`, файлы `pay.js` и `package.json`,
память 128 МБ, таймаут 15 с, **публичная**. Сервисный аккаунт с ролью `ydb.editor`, переменные:

| Переменная | Что это |
|---|---|
| `YDB_DATABASE` | путь к базе (можно ту же, что у «Кольца»: таблицы `pay_orders` и `pay_codes` создадутся сами) |
| `ROBO_LOGIN`, `ROBO_PASS1`, `ROBO_PASS2` | идентификатор магазина и пароли №1 и №2 из «Технических настроек» Robokassa (алгоритм MD5) |
| `ROBO_TEST=1` | тестовые платежи; тогда пароли — тестовые. Убрать после проверки |
| `TICKET_SECRET` | та же строка, что у функции `antiplagiat` |
| `BOT_SECRET`, `BOT_WEBHOOK_URL` | для оплаты заказов бота «Без хвостов» (ниже) |

В Robokassa → «Технические настройки»: Result URL — `https://functions.yandexcloud.net/<id>?robokassa=result`, метод POST;
Success URL — `https://arktika-app.ru/antiplagiat/?pay=ok`; Fail URL — `https://arktika-app.ru/antiplagiat/?pay=fail`.
Адрес функции вписать в `PAY_DEFAULT` в `site/antiplagiat/index.html`, заполнить ФИО, ИНН и почту в
`site/antiplagiat/oferta.html`. Блок «Полная проверка» и цены появляются на странице, только когда оплата настроена
и `yandex.js` сообщает, что поиск Яндекса включён и платный.

Запросы (POST, JSON): `{action:"plans"}` · `{action:"create", plan}` → `{order, url}` · `{action:"status", order}` →
`{paid, code, left, until}` · `{action:"balance", code}` · `{action:"ticket", code}` → `{ticket, left, until}` (402 —
проверки кончились или срок истёк).

**Заказы бота.** Сервер бота создаёт заказ сам: `{action:"create", purpose:"bot", order_id, amount, description, sig}`,
где `sig` = HMAC-SHA256(`BOT_SECRET`, `"<order_id>:<amount с двумя знаками>"`) в hex, например `"z1:500.00"`. В ответ —
`url` для оплаты. После оплаты функция шлёт на `BOT_WEBHOOK_URL` POST `{order_id, amount, inv, paid_at}` с заголовком
`X-Signature` = HMAC-SHA256(`BOT_SECRET`, тело). Если бот не ответил 2xx, функция не подтверждает уведомление и
Robokassa присылает его ещё раз.

Проверить у себя: `python3 antiplagiat/site_dev.py --fake-yandex` (нужен Node.js) — вместо Robokassa страница
`/pay-fake` сразу «оплачивает» заказ. Тесты: `node --test antiplagiat-api/tests/pay.test.mjs`.

## «Кольцо САФУ» (`ring.js`)

Общая база работ, которые студенты добавили сами (кнопка «В Кольцо САФУ» в отчёте). Страница присылает «отпечатки»
текста — хеши троек основ слов; сервер находит работы с общими отпечатками и отдаёт **только куски вокруг совпадений**,
чужую работу целиком получить нельзя. Удаление — по ключу, который хранится в браузере автора.

Выложить: отдельная функция `antiplagiat-ring`, Node.js 22, точка входа `ring.handler`, файлы `ring.js` и `package.json`
(Yandex сам поставит `ydb-sdk`), память 256 МБ, таймаут 30 с, **публичная**. Сервисный аккаунт с ролью `ydb.editor`,
переменная `YDB_DATABASE` — путь к базе (можно ту же, что у «Отметок»: таблицы `ring_docs` и `ring_fp` создадутся сами).
Адрес функции вписать в `RING_DEFAULT` в `site/antiplagiat/index.html`.

Бесплатный объём YDB (1 ГБ и 1 млн единиц запросов в месяц) — это тысячи работ и проверок.
