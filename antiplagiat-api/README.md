# Помощник антиплагиата (arktika-app.ru/antiplagiat/)

Проверка текста идёт прямо в браузере (`site/antiplagiat/engine.js`): текст никуда не отправляется. Википедия
отвечает браузеру напрямую, а чужие сайты, выдачу поисковиков и поиск КиберЛенинки браузер прочитать не может —
у них нет разрешения CORS. Их скачивает этот помощник: `GET ?url=<адрес>` → тело страницы как есть.

| Файл | Что делает |
|---|---|
| `yandex.js` | функция Yandex Cloud (основной вариант: из России открывается везде, сайты видят российский адрес) |
| `worker.js` | Cloudflare Worker (запасной вариант, тот же протокол) |

Протокол:

- `GET` без параметров → `{"ok":true}` — страница так проверяет, что помощник жив;
- `GET ?url=…` → тело страницы (до 2,5 МБ); код ответа сайта — в заголовке `X-Status`, итоговый адрес — в `X-Final-Url`;
- `POST ?url=https://cyberleninka.ru/api/search` → поиск КиберЛенинки (другие адреса для POST запрещены).

Помощник ничего не хранит. Скачивает только из открытого интернета: адреса внутренних сетей, IP-адреса вместо имён
и нестандартные порты запрещены (в `yandex.js` проверяется и то, куда ведёт имя, на каждой переадресации). Ответы
с разрешением CORS получают только `arktika-app.ru` и `localhost:8790`.

## Проверить у себя

```
python3 antiplagiat/site_dev.py
```
Открыть `http://localhost:8790/antiplagiat/` — на localhost страница сама использует встроенного помощника `/proxy`.

## Выложить (бесплатно, как функцию «Отметок»)

1. Yandex Cloud → Cloud Functions → «Создать функцию», имя `antiplagiat`.
2. Сделать функцию **публичной**.
3. Редактор: среда **Node.js 22**, точка входа `index.handler`, в файл `index.js` вставить содержимое `yandex.js`.
4. Параметры: память **128 МБ**, таймаут **15 секунд**. Создать версию.
5. Скопировать ссылку вида `https://functions.yandexcloud.net/…` и вписать её в `API_DEFAULT` в
   `site/antiplagiat/index.html`.

Бесплатно в месяц: 1 млн вызовов и 10 ГБ×ч. Одна проверка — около 60–200 вызовов по ~1 секунде на 128 МБ, то есть
бесплатного объёма хватает примерно на 5 тысяч проверок в месяц. Без привязанной карты при превышении функция
просто перестаёт отвечать до следующего месяца, а страница продолжает проверять по Википедии.

Cloudflare (запасной вариант): Workers → «Create» → вставить `worker.js` → Deploy; ссылку `…workers.dev` можно
вписать в `API_DEFAULT` вместо функции Yandex. Бесплатно 100 тысяч запросов в день.

**Учти:** помощник — открытый «скачиватель страниц». Браузеры с чужих сайтов им воспользоваться не смогут
(нет разрешения CORS), но программа, написанная специально, — сможет, в пределах бесплатных лимитов.
