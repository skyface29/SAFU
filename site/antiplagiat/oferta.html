3. Оказание услуги

3.1. Услуга считается оказанной в момент запуска проверки по коду. Результат проверки показывается в браузере Заказчика.

3.2. Проверка идёт по открытым источникам. Исполнитель не гарантирует совпадения процента с результатом других систем, в том числе вузовского «Антиплагиата»: закрытые базы (диссертации РГБ, полные тексты eLibrary, работы других вузов) ему недоступны.

3.3. Текст работы не загружается на сервер Исполнителя. В поисковые системы уходят только короткие фразы из текста.

3.4. Код доступа — единственное подтверждение оплаченных проверок. Заказчик сам хранит его и не передаёт третьим лицам.

4. Возврат

4.1. За неиспользованные проверки Заказчик может вернуть деньги в течение срока действия кода, написав Исполнителю (раздел «Контакты») и указав код. Возвращается стоимость неиспользованных проверок пропорционально цене тарифа.

4.2. Если проверка не выполнилась по вине сервиса (поиск Яндекса не ответил), Исполнитель возвращает проверку на код или деньги по выбору Заказчика.

5.1. Ответственность Исполнителя ограничена стоимостью оплаченной услуги.

5.2. Исполнитель не отвечает за решения, которые третьи лица принимают на основании результата проверки.

6.1. Исполнитель не собирает имя, почту и телефон Заказчика. Данные карты и почту для чека обрабатывает Robokassa по своим правилам.
