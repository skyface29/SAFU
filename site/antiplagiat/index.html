Проверка идёт прямо в вашем браузере: текст не загружается ни на какой сервер и нигде не сохраняется. В поисковые системы уходят только короткие фразы из текста — чтобы найти страницы-кандидаты, которые затем скачиваются и сравниваются здесь же. Коллекция документов хранится только в этом браузере.
Поиск идёт по открытым источникам. Закрытые базы — диссертации РГБ, полные тексты eLibrary, работы других вузов — доступны только самим системам-владельцам, поэтому процент может отличаться от вузовского «Антиплагиата».
