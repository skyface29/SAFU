Как считаем. «Посетитель» — это браузер: у каждого свой случайный номер, поэтому один человек, открывший сайт пять раз, — один посетитель, а его телефон и ноутбук — двое. «Сети» — разные IP-адреса: они точнее для одного человека с двумя устройствами, но занижают общежития и Wi‑Fi САФУ, где сотни студентов выходят в интернет с одного адреса. Правда — между этими двумя числами. Тип устройства, система и браузер определяются на сервере по User-Agent; роботы поисковиков не считаются. IP не хранится: только обезличенный отпечаток, соль которого меняется каждые сутки. Приложение «Арктика» не учитывается, только сайт.
