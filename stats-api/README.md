# Пульс — сколько людей сейчас на сайте (arktika-app.ru/admin/)

Страницы с `<script src="../pulse.js" data-section="…" defer>` (сейчас: Расписание, Отметки, Антиплагиат) при открытии и
потом раз в 5 минут, пока вкладка видна, отправляют случайный номер браузера и раздел. Имён, IP и содержимого страниц нет.
Админка `site/admin/` показывает: сколько людей сейчас (за 6 минут), за сегодня, за неделю, по разделам и график
по часам за двое суток. Видна только тому, кто знает пароль (переменная `ADMIN_TOKEN` функции).

## Выложить

1. Yandex Cloud → Cloud Functions → функция `arktika-pulse`: Node.js 22, файлы `pulse.js` и `package.json`, точка входа
   `pulse.handler`, память 128 МБ, таймаут 10 с, **публичная**.
2. Сервисный аккаунт функции — с ролью `ydb.editor`; переменные `YDB_DATABASE` (путь к базе, можно ту же, что у «Отметок»;
   таблица `pulse` создастся сама) и `ADMIN_TOKEN` — длинный случайный пароль админки.
3. Адрес функции вписать в `PULSE` в `site/pulse.js` и в `PULSE_DEFAULT` в `site/admin/index.html`.

## Сколько стоит — ничего

Счётчик отправляет запрос при открытии сайта и потом раз в 5 минут, пока вкладка на экране. Админка обновляется раз в минуту
и только пока открыта. 100 человек онлайн весь день — около 20 тысяч вызовов в сутки, это ~600 тысяч в месяц из бесплатного
миллиона. На всякий случай у функции есть потолок `DAILY_CAP` (12 000 записей в сутки на экземпляр): дальше она молча
перестаёт записывать, и счёт не придёт. Помните, что бесплатный миллион общий на все функции облака (Отметки, Антиплагиат).

Проверить у себя: `python3 antiplagiat/site_dev.py` → открыть разделы, затем `http://localhost:8790/admin/`, пароль `local`.
