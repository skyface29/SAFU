# Пульс — сколько людей сейчас на сайте (arktika-app.ru/admin/)

Страницы с `<script src="../pulse.js" data-section="…" defer>` (сейчас: Расписание, Отметки, Антиплагиат), пока вкладка
открыта и видна, раз в минуту отправляют случайный номер браузера и раздел. Имён, IP и содержимого страниц нет.
Админка `site/admin/` показывает: сколько людей сейчас (за 2,5 минуты), за сегодня, за неделю, по разделам и график
по часам за двое суток. Видна только тому, кто знает пароль (переменная `ADMIN_TOKEN` функции).

## Выложить

1. Yandex Cloud → Cloud Functions → функция `arktika-pulse`: Node.js 22, файлы `pulse.js` и `package.json`, точка входа
   `pulse.handler`, память 128 МБ, таймаут 10 с, **публичная**.
2. Сервисный аккаунт функции — с ролью `ydb.editor`; переменные `YDB_DATABASE` (путь к базе, можно ту же, что у «Отметок»;
   таблица `pulse` создастся сама) и `ADMIN_TOKEN` — длинный случайный пароль админки.
3. Адрес функции вписать в `PULSE` в `site/pulse.js` и в `PULSE_DEFAULT` в `site/admin/index.html`.

## Сколько стоит

Один открытый сайт — один вызов функции в минуту. 100 человек одновременно в течение дня — около 100 тысяч вызовов в сутки,
то есть бесплатный миллион вызовов в месяц закончится примерно за 10 дней такого потока; дальше — небольшая плата по
тарифу Cloud Functions и YDB. При маленькой нагрузке — бесплатно. Чтобы считать реже, поменяйте `60000` в `pulse.js`
и окно `ONLINE_MS` в `pulse.js` функции (держите окно в 2,5 раза больше интервала).

Проверить у себя: `python3 antiplagiat/site_dev.py` → открыть разделы, затем `http://localhost:8790/admin/`, пароль `local`.
