# Как запустить бота — по шагам

**Что получится:** бот в Telegram, где один человек записывает ДЗ, а оно приходит всей группе. Плюс мини-приложение — кнопка «ДЗ» в чате с ботом.

**План:**

| Шаг | Что делаем | Время | Деньги |
|---|---|---|---|
| 1 | Создаём бота в Telegram | 5 минут | бесплатно |
| 2 | Пробуем на своём компьютере | 15 минут | бесплатно |
| 3–5 | Сервер — чтобы бот работал всегда | 30 минут | аренда сервера, обычно несколько сотен ₽ в месяц |
| 6 | Домен — чтобы заработало мини-приложение | 15 минут + ожидание до часа | домен .ru — от пары сотен ₽ в год |
| 7 | Подключаем группы и преподавателей | — | — |

Шаг 2 можно пропустить и сразу ставить на сервер. Шаг 6 можно сделать позже: бот работает и без домена, не будет только кнопки «ДЗ».

---

## Шаг 1. Создаём бота

1. В Telegram найди **@BotFather** (с синей галочкой) и нажми **Запустить**.
2. Отправь ему: `/newbot`
3. Он спросит название — напиши, например: `Домашка САФУ`
4. Он спросит username — латиницей и обязательно с `bot` в конце, например: `safu_dz_bot`. Занято — придумай другой.
5. Придёт сообщение с **токеном** — длинная строка вида `7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Скопируй и сохрани. **Никому не показывай**: с токеном кто угодно управляет ботом.
6. Отправь BotFather: `/setjoingroups` → нажми своего бота → **Enable**. Это чтобы бота можно было добавить в чат группы.
7. Узнай свой Telegram id: найди **@userinfobot** → Запустить. Он пришлёт `Id: 123456789` — запиши эти цифры. С ними ты будешь админом бота: подтверждать преподавателей и смотреть `/stats`.

---

## Шаг 2. Пробуем на своём компьютере (Windows)

Бот будет работать, пока компьютер включён и открыто окно. Для пробы — самое то.

1. **Node.js.** Зайди на https://nodejs.org → большая кнопка **LTS** → скачай и установи (везде «Далее»). Нужна версия 22 или новее.
2. **Код.** Открой ссылку — скачается архив:
   https://github.com/skyface29/SAFU/archive/refs/heads/claude/telegram-homework-bot.zip
   Распакуй его: правой кнопкой по архиву → **Извлечь всё**.
3. Открой распакованную папку, а в ней — папку **telegram**.
4. **Чёрное окно.** Кликни в адресную строку Проводника (где написан путь), сотри всё, напиши `cmd` и нажми **Enter**. Откроется чёрное окно — сразу в этой папке.
5. **Настройки.** В чёрном окне напиши `notepad .env` и нажми Enter. Блокнот спросит «Создать новый файл?» → **Да**. Вставь две строки, подставив свои значения из шага 1:
   ```
   BOT_TOKEN=7123456789:AAHxxxxxxxxxxxxxxxxxxxxxxxxxxxx
   ADMIN_IDS=123456789
   ```
   Сохрани (**Ctrl+S**) и закрой Блокнот.
6. **Запуск.** В чёрном окне по очереди, каждую команду — Enter и дождаться конца:
   ```
   npm install
   npm run build
   npm start
   ```
   `npm install` скачивает библиотеки — 1–3 минуты. Жёлтые предупреждения — это нормально.
7. Когда появится строка **`Бот слушает Telegram`** — бот работает. Открой его в Telegram (`t.me/твой_username`), нажми **Запустить** → «Я студент» → номер группы.
8. **Проверка.** Напиши боту: `Матан: № 5, 6 стр 45` → выбери срок → **Сохранить**. Позови одногруппника: `/invite` → «Отправить ребятам». Когда он зайдёт и ты запишешь ещё одно ДЗ — оно придёт и ему.
9. **Остановить** — закрой чёрное окно. **Запустить снова** — в папке telegram опять `cmd` → `npm start`.

---

## Шаг 3. Арендуем сервер

Сервер — это компьютер в интернете, который работает всегда.

1. Зарегистрируйся у российского хостинга с VPS (облачными серверами): например, **Timeweb Cloud**, **Selectel**, **REG.RU**, **Beget** — они принимают российские карты. Российский — потому что сайт РУЗ может не открываться из-за рубежа.
2. Создай сервер (VPS, «облачный сервер»):
   - система — **Ubuntu 24.04**;
   - **1 ядро, 2 ГБ памяти** (на 1 ГБ сборка может не поместиться), диск от 10 ГБ;
   - самый дешёвый тариф с такими параметрами.
3. Хостинг покажет на странице сервера (или пришлёт письмом) **IP-адрес** (вида `185.12.34.56`) и **пароль root**. Запиши оба.

---

## Шаг 4. Заходим на сервер

1. На своём компьютере: **Пуск** → напиши `cmd` → Enter.
2. Напиши, подставив свой IP: `ssh root@185.12.34.56` → Enter.
3. В первый раз спросит `Are you sure you want to continue connecting` → напиши `yes` → Enter.
4. Спросит `password` → вставь пароль (вставка в этом окне — **правой кнопкой мыши**). **Символы при вводе не видны — так и должно быть.** Нажми Enter.
5. Если видишь строку, которая заканчивается на `#` (например `root@server:~#`) — ты на сервере. Все команды дальше вводятся здесь.

---

## Шаг 5. Ставим бота на сервер

Вставляй команды по одной (правой кнопкой) и жди, пока снова появится `#`.

1. **Программы:**
   ```
   apt update && apt install -y docker.io docker-compose-v2 git
   ```
2. **Код и настройки:**
   ```
   git clone -b claude/telegram-homework-bot https://github.com/skyface29/SAFU.git
   cd SAFU/telegram
   cp .env.example .env
   nano .env
   ```
3. Откроется редактор. Стрелками на клавиатуре дойди до строки `BOT_TOKEN=` и вставь после `=` свой токен (правой кнопкой). Так же в строке `ADMIN_IDS=` — свой id. **DOMAIN пока не трогай.**
   Сохранить: **Ctrl+O**, потом **Enter**. Выйти: **Ctrl+X**.
4. **Важно:** если бот ещё запущен на твоём компьютере (шаг 2) — закрой там чёрное окно. Один бот не может работать в двух местах сразу.
5. **Запуск** (в первый раз 3–5 минут):
   ```
   docker compose up -d --build bot
   ```
6. **Проверка:**
   ```
   docker compose logs bot
   ```
   Должна быть строка `Бот слушает Telegram`. Напиши боту `/start` — он ответит.

Готово: бот работает всегда, и после перезагрузки сервера тоже. Всё записанное хранится в папке `SAFU/telegram/data`, копия базы делается сама каждый день.

Окно с сервером можно закрыть — бот продолжит работать.

---

## Шаг 6. Домен и мини-приложение

Мини-приложение Telegram открывается только по адресу с `https`, поэтому нужен домен.

1. **Купи домен**, например у REG.RU, Timeweb или nic.ru.
2. В панели управления доменом найди **DNS** («Управление DNS», «Ресурсные записи») и добавь запись:
   - тип: **A**;
   - имя (хост): **dz** — тогда адрес будет `dz.твойдомен.ru` (или `@`, если хочешь просто `твойдомен.ru`);
   - значение: **IP твоего сервера**.

   Сохрани. Запись начинает работать через 10–60 минут.
3. **Проверка:** на своём компьютере в `cmd` напиши `ping dz.твойдомен.ru` — должен показаться IP сервера.
4. Зайди на сервер (шаг 4) и выполни:
   ```
   cd ~/SAFU/telegram
   nano .env
   ```
   В строке `DOMAIN=` впиши адрес **без https://**, например `DOMAIN=dz.твойдомен.ru`. Сохрани: Ctrl+O, Enter, Ctrl+X.
5. Запусти всё вместе (бот + раздача https):
   ```
   docker compose up -d --build
   ```
6. Открой в браузере `https://dz.твойдомен.ru/health` — должно показать `{"ok":true,...}`. Сертификат https получается сам, это может занять минуту.
7. В Telegram закрой и снова открой чат с ботом. Слева от поля ввода появится кнопка **«ДЗ»** — это и есть мини-приложение. Нет кнопки — перезапусти Telegram.

**Необязательно:** ссылка «открыть приложение» прямо из чатов групп. В @BotFather отправь `/newapp` → выбери бота и отвечай на вопросы. Когда спросит адрес — `https://dz.твойдомен.ru`, когда спросит короткое имя — например `dz`. Потом на сервере в `.env` впиши `APP_NAME=dz` и выполни `docker compose up -d`.

## Шаг 7. Подключаем группы и преподавателей

- **Своя группа:** в боте `/invite` → **«Отправить ребятам»** → выбери чат группы. Кто нажмёт ссылку — сразу попадёт в твою группу.
- **Бот в чате группы:** `/invite` → **«Добавить в чат группы»** → выбери чат. Если бот сам не написал «Чат привязан», админ чата пишет там: `/group 151621` (номер вашей группы). После этого новые ДЗ приходят в чат, а в 20:00 — что сдавать завтра. Записать прямо из чата: `/add Матан: № 5, 6`.
- **Другие группы САФУ:** просто дай старостам ссылку на бота (`t.me/твой_username`). Каждый вводит номер своей группы — все группы вуза бот уже знает из РУЗ.
- **Преподаватели:** нажимают «Я преподаватель» и пишут фамилию. Тебе придёт сообщение с кнопками **«✅ Подтвердить» / «❌ Это не он»** — убедись, что это правда преподаватель, и нажми.
- **Статистика:** `/stats` в боте — сколько людей, групп, чатов и ДЗ.

---

## Обновить бота (когда в коде что-то поправили)

```
cd ~/SAFU/telegram
git pull
docker compose up -d --build
```

Записанные ДЗ при обновлении не теряются.

## Если что-то не так

| Что видишь | Что делать |
|---|---|
| `"npm" не является внутренней или внешней командой` | Node.js не установлен, или чёрное окно открыто раньше установки. Закрой окно и открой заново (шаг 2, пункт 4). |
| `Нужен BOT_TOKEN` | Файл назвался `.env.txt`. В чёрном окне напиши `ren .env.txt .env` и запусти снова. |
| `401: Unauthorized` | Токен скопирован с ошибкой. Скопируй его ещё раз из сообщения BotFather. |
| `409: Conflict` | Бот запущен в двух местах. Останови один (на компьютере — закрой окно). |
| Бот не находит группу | Сервер не достучался до РУЗ. На сервере: `curl -I https://ruz.narfu.ru`. Ошибка или тишина — нужен другой, российский сервер. |
| `docker compose up` падает при скачивании (`docker.io`, `toomanyrequests`, `connection reset`) | С сервера недоступен Docker Hub. Выполни команду ниже и повтори запуск. |
| `https://домен/health` не открывается | DNS ещё не обновился — подожди час. Проверь `ping` (шаг 6, пункт 3) и посмотри `docker compose logs caddy`. |
| Нет кнопки «ДЗ» | Перезапусти Telegram. Проверь, что в `.env` записан `DOMAIN` без `https://`, и выполни `docker compose up -d`. |
| Бот молчит, а что не так — непонятно | `docker compose logs bot` — скопируй, что там написано, и пришли разработчику. |

Команда, если недоступен Docker Hub:
```
echo '{"registry-mirrors":["https://mirror.gcr.io"]}' > /etc/docker/daemon.json && systemctl restart docker
```
