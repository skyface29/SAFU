# API отметок (arktika-app.ru/otmetki/)

Сервер для страницы отметок посещаемости. Хранит только шифр: фамилии, отметки и предметы шифруются
в браузере ключом из кода группы (HKDF + AES-GCM), код на сервер не попадает. Сервер видит номер группы
(хеш из кода), ключи записей и хеш пропуска на запись.

| Файл | Что делает |
|---|---|
| `core.js` | протокол: `create`, `get`, `put`, `del`, `month`, `student`; проверки и ограничения |
| `store-s3.js` | хранилище в Object Storage (по умолчанию) |
| `store-ydb.js` | хранилище в YDB serverless, таблица `kv(g, k, d, upd)` создаётся сама (про запас) |
| `store-mem.js` | хранилище в памяти для локальной проверки |
| `index.js` | точка входа Yandex Cloud Functions |
| `dev-server.js` | сайт + API на одном порту для проверки у себя |
| `pack.js` | сборка в один файл `dist/index.js` + `dist/package.json` (+ zip) |

Ключи хранилища: `_w` (хеш пропуска), `meta` (список группы), `st/<метка>` (карточка студента),
`l/<дата>T<время>-<хеш>` (пара: шифр для старост и метки студентов), `s/<метка>/<дата>T…` (часть
одного студента). YDB берёт плату за прочитанные строки, поэтому страница студента читает только свои строки.
Примерно: группа из 25 человек и 100 пар в месяц ≈ 30 тыс. RU в месяц; бесплатно 1 млн RU.

## Проверить у себя

```
node otmetki-api/dev-server.js 8790 <папка с данными ветки ruz-data>
```
Открыть `http://localhost:8790/otmetki/`, в консоли браузера: `localStorage.setItem('otmetki.api','/api')`.

## Развернуть (Yandex Cloud, бесплатный уровень)

Сейчас работает так (функция `otmetki`, каталог default):
1. Object Storage: приватный бакет `otmetki-arktika-data`, лимит 1 ГБ.
2. Сервисный аккаунт `otmetki-fn` с ролью `storage.editor` на каталог.
3. Cloud Functions: функция `otmetki`, **публичная**, Node.js 22, точка входа `index.handler`, таймаут 15 с,
   128 МБ, сервисный аккаунт `otmetki-fn`. Код: `node pack.js` → `dist/index.js` (зависимостей нет).
4. Адрес `https://functions.yandexcloud.net/d4e8m5ak49b1ggo0cbkh` вписан в `API_DEFAULT` в `site/otmetki/index.html`.

Ключей и токенов нет: функция ходит в бакет с IAM-токеном своего сервисного аккаунта (`context.token`,
заголовок `X-YaCloud-SubjectToken`). В бакете на месяц группы один объект, поэтому отметка пары стоит
1–2 чтения и 1 запись, а месяц для старосты или студента — 1 чтение.

YDB (`store-ydb.js`, `STORE=ydb`) оставлен про запас: в октябре 2026, после атак на дата-центры Яндекса,
serverless YDB не успевал компилировать даже простые запросы.
