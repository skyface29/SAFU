# Выпуск в App Store — «Сполох»

Всё, что нужно, чтобы отправить приложение на проверку Apple. Тексты ниже можно копировать в App Store Connect как есть.

## 1. Название

**Сполох** — так на Севере (в поморском говоре) называют северное сияние. Название своё, без чужих марок: в нём нет «САФУ», логотипов университета и названий других приложений.

| Поле | Значение | Лимит |
|---|---|---|
| Название в App Store | `Сполох — пары и учёба` | 30 |
| Подзаголовок | `Расписание, ДЗ и сайты вуза` | 30 |
| Название на экране «Домой» | `Сполох` | — |
| Bundle ID | `ru.student.safuhub` (виджет: `ru.student.safuhub.widget`) | — |

Если App Store Connect скажет, что название занято, запасные: `Сполох: учёба и пары`, `Двина — пары и ДЗ`, `Северное сияние — учёба`.

**Ключевые слова** (100 символов, через запятую без пробелов; марки и чужие названия сюда класть нельзя — правило 2.3.7):

```
расписание,пары,домашка,дз,студент,вуз,универ,зачётка,сессия,БРС,конспект,лекции,матрицы,доска
```

## 2. Описание

**Промотекст** (170):
> Домашка сама встаёт к следующей практике и одной кнопкой летит в чат группы. Пары, сайты вуза, файлы и фото доски — в одном месте.

**Описание:**

```
Сполох — всё для учёбы в одном месте: расписание, домашка, сайты вуза, файлы по предметам и фото доски.

РАСПИСАНИЕ
• Пары группы подтягиваются из открытого расписания вуза сами: выбрал школу и группу — готово

• Замены и отмены пар — уведомлением, даже когда приложение закрыто

ДОМАШКА

САЙТЫ И ФАЙЛЫ ПОВЕРХ ВСЕГО

Без рекламы, аналитики и своих серверов: данные хранятся только на телефоне.

Неофициальное приложение. Сделано студентом и не связано с университетом.
```

## 4. Возрастной рейтинг (анкета)

Отвечать честно; везде «Нет», кроме:
- **Мультипликационное или фэнтезийное насилие — «Редко/слабо»**: в пасхалке «Ядерный гриб» экран разлетается от взрыва (людей нет).
- **Неограниченный доступ к интернету — «Да»**: внутри открываются сайты университета и любые свои ссылки.

Рейтинг App Store Connect посчитает сам; из-за встроенного браузера он будет взрослым — для приложения студентов это не мешает.

## 5. «Конфиденциальность приложения» (App Privacy)

- Собираете ли вы данные? — **Да**, один тип:
  - **Другой контент пользователя** (Other User Content) — текст расшифровки лекции уходит в GigaChat или Claude, **только если человек сам ввёл свой ключ и разрешил**.
  - Цель: функциональность приложения. Не связан с личностью. Не используется для отслеживания.
- Всё остальное (расписание, пароли, файлы, фото) хранится только на телефоне и разработчику не уходит — это «не собирается».

## 6. Заметки для проверяющего (App Review Information)

Вставить в поле «Notes»:

```
Сполох — неофициальное приложение для студентов Северного (Арктического) федерального университета (Архангельск).

Как проверить без учётной записи:
1. При первом запуске нажмите «Начать», введите любое имя.
2. Школа: «Высшая школа информационных технологий и автоматизированных систем», группа: 151621.
   Расписание загружается из открытого расписания вуза (ruz.narfu.ru) без входа.
3. Домашка: вкладка «ДЗ» → «+». Срок сам встаёт к следующей практике.
4. Матрицы: Главная → Инструменты → Матрицы (можно ввести числа вручную, есть решение по шагам).

Сайты (Sakai, почта, личный кабинет) — это сайты самого университета, они открываются во встроенном браузере и требуют учётную запись студента. Демо-аккаунта у вуза нет; приложение их не обслуживает и не хранит пароли нигде, кроме связки ключей iPhone.

Фоновый режим audio: запись лекции продолжается, когда экран выключен (Инструменты → Лекции).
ИИ-конспект (GigaChat/Claude) работает только с ключом пользователя и после явного разрешения на отправку текста.
В приложении есть безобидные пасхалки и мини-игра; их список с подсказками — Профиль → «Разработчик и о приложении» → «Пасхалки». Найденные пасхалки открывают дополнительные иконки приложения (как достижения в игре) — без покупок и без кодов.
```

Контакты: имя, телефон и почта — свои. Демо-аккаунт: «Вход не требуется».

## 8. Как загрузить сборку без Mac

В репозитории есть workflow **App Store (TestFlight)** (`.github/workflows/appstore.yml`). Он собирает, подписывает сертификатом Apple и сам загружает сборку в App Store Connect.

1. Вступить в Apple Developer Program (платно, раз в год) — нужен именно платный аккаунт.
2. App Store Connect → «Приложения» → «+» → «Новое приложение»: платформа iOS, название `Сполох — пары и учёба`, язык русский, Bundle ID `ru.student.safuhub` (если его нет в списке — сначала developer.apple.com → Identifiers → «+» → App IDs, то же для `ru.student.safuhub.widget`).
3. App Store Connect → «Пользователи и доступ» → «Интеграции» → «Ключи App Store Connect API» → создать ключ с ролью **Admin**, скачать `AuthKey_XXXX.p8` (скачивается один раз!).
4. В репозитории GitHub: Settings → Secrets and variables → Actions → добавить `ASC_KEY_ID`, `ASC_ISSUER_ID`, `ASC_KEY_P8` (текст файла .p8 целиком), `TEAM_ID`.
5. Actions → **App Store (TestFlight)** → Run workflow. Через 15–40 минут сборка появится в TestFlight.
6. Проверить сборку в TestFlight на своём iPhone, потом в App Store Connect выбрать её в версии 18.1 и нажать «Отправить на проверку».
