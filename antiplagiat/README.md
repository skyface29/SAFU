# Айсберг — бесплатная проверка на заимствования

Локальный аналог «Антиплагиата»: без оплаты, регистрации и лимитов, с полным отчётом.
Работает на вашем компьютере, нужен только Python 3.8+ и интернет.

## Запуск

- **macOS** — двойной щелчок по `Запустить.command`
- **Windows** — двойной щелчок по `Запустить.bat`
- **или в терминале:** `python3 app.py` — и откройте http://localhost:8765

## Что умеет

- Принимает текст, `.docx`, `.pdf`, `.txt`.
- Ищет источники в интернете, Википедии, КиберЛенинке и в вашей собственной коллекции документов.
- Находит дословные совпадения и перефразирование: смену падежей и времён, замену, вставку и перестановку слов.
- Распознаёт уловки: подмену букв латиницей, невидимые символы, скрытый белый текст и микрошрифт в `.docx`.
- Отдельно считает цитаты в кавычках и исключает список литературы.
- Показывает каждый фрагмент с источником и ссылкой; источники можно исключать — процент пересчитывается.
- Выгружает отчёт в файл и на печать.

## Как устроено

| Файл | Назначение |
| --- | --- |
| `app.py` | локальный сервер и очередь проверок |
| `antiplag/text.py` | очистка текста, разбор на слова, основы слов, поиск уловок |
| `antiplag/match.py` | сравнение с источником: шинглы + выравнивание фрагментов |
| `antiplag/sources.py` | веб-поиск, Википедия, КиберЛенинка, загрузка страниц |
| `antiplag/check.py` | ход проверки: запросы → кандидаты → сравнение → отчёт |
| `antiplag/extract.py` | чтение HTML, DOCX, PDF |
| `passenger_wsgi.py`, `deploy/` | запуск на сервере: хостинг с Passenger, служба и nginx для VPS |
| `static/index.html` | интерфейс |
| `library/` | ваша коллекция документов (создаётся при добавлении) |

## Честно об ограничениях

- **Закрытые базы недоступны.** Диссертации РГБ, полные тексты eLibrary и «Кольцо вузов» есть только у самих
  систем-владельцев. Если работа списана оттуда, её увидит только вузовский «Антиплагиат», поэтому процент здесь и в
  вузе может отличаться.
- **Бесплатный веб-поиск ограничивает частоту запросов.** Программа ходит в него бережно и при отказе переключается на
  запасной поисковик. Быстрее и полнее поиск становится со своим ключом Brave Search или Google Programmable Search —
  он вводится в «Коллекция и настройки». Работа с ключами написана по документации этих сервисов, но без ключа
  не проверялась.
- **PDF-источники из сети** читаются, только если установлен пакет `pypdf` (`pip3 install pypdf`). Ваши собственные
  PDF читаются в браузере и без него.
- **Определения текста, написанного нейросетью, нет**: без обученной модели такая оценка давала бы ложные обвинения.

## Размещение на сервере (поддомен)

На сервере сервис запускается в **публичном режиме**: отключены личная коллекция и ввод ключей через интерфейс,
ограничено число проверок (по умолчанию 12 в час с одного адреса и 3 одновременно на сервере), страницы скачиваются
только из открытого интернета, готовые отчёты удаляются через час.

**Свой сервер (VPS).** Скопировать проект в `/opt/iceberg`, подключить службу из `deploy/iceberg.service` и поддомен из
`deploy/nginx.conf`, выпустить сертификат (`certbot --nginx`).

**Виртуальный хостинг Beget.** В панели создать поддомен, в папку сайта (рядом с `public_html`) положить проект,
файл `passenger_wsgi.py` уже есть; `deploy/htaccess-beget.txt` сохранить там же как `.htaccess`. Перезапуск —
`touch tmp/restart.txt`. Точные пути и версия Python зависят от аккаунта — этот вариант написан по общей схеме
Passenger и на Beget ещё не проверен.

Настройки через переменные окружения: `ICEBERG_MAX_RUNNING` (одновременных проверок), `ICEBERG_PER_HOUR`
(проверок в час с адреса), `PORT`, `HOST`. Ключи поиска на сервере кладутся в `config.json` вручную:
`{"brave": "…"}` или `{"google": "…", "google_cx": "…"}`.

**Важно про нагрузку:** все посетители ходят в бесплатные поисковики с одного адреса сервера, а те пускают
примерно один запрос в 9–10 секунд. При нескольких одновременных проверках каждая будет находить меньше.
Для публичного сервиса с посетителями свой ключ поиска практически обязателен.
